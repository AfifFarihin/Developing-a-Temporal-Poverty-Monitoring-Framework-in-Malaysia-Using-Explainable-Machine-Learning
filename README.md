# Temporal Poverty Source Code

Source-code package for **Malaysia state-level temporal poverty monitoring** using official DOSM poverty statistics, satellite/geospatial proxy features, leakage-aware Leave-One-State-Out validation, Random Forest, RF SHAP, and a local Dash dashboard.

This README is intended to be read from inside the Moodle source-code folder:
`Muhammad Afif Farihin Bin Mohammad-TP076690-APD3F2509CS(DA)-Source Code`.

## Final Scope

- Country: Malaysia.
- Unit of analysis: 16 states and federal territories.
- Survey years: 2002, 2004, 2007, 2009, 2012, 2014, 2016, 2019, 2020, and 2022.
- Primary target: absolute poverty.
- Selected point predictor: Random Forest full-feature state-level model.
- Explainability: RF SHAP for the selected model, with XGBoost retained only as comparator evidence.
- Dashboard: stakeholder-facing local Dash app for monitoring, prioritisation, research transparency, and community accountability.

## Certified State-Level Results

| Target | Selected model | MAE | RMSE | R² | Spearman | Finding |
|---|---:|---:|---:|---:|---:|---|
| Absolute poverty | Random Forest full features | 2.524 pp | 4.564 pp | 0.218 | 0.787 | Satellite/geospatial features improve MAE by 0.44 pp over the year-only baseline. |
| Relative poverty | Year-only XGBoost | 2.240 pp | 2.892 pp | 0.246 | 0.428 | Relative poverty is mainly year/trend driven in this dataset. |

The full-feature RF is retained as the selected interpretable absolute-poverty monitoring model. `rf_sensor_safe` is reported separately as the lowest-error absolute benchmark (MAE 2.362 pp), and `current_xgb` remains the strongest rank comparator.

## Manual Notebook Workflow

Create the environment from the run guide inside this source-code folder, then open and run these notebooks in order:

1. `notebooks/00_dosm_raw_to_labels.ipynb`
2. `notebooks/01_malaysia_data_preparation.ipynb`
3. `notebooks/02_malaysia_spatial_features.ipynb`
4. `notebooks/03_model_training_evaluation.ipynb`
5. `notebooks/04_dashboard_artifacts.ipynb`

Notebook `00_dosm_raw_to_labels.ipynb` records the official DOSM raw poverty-label lineage and validates those labels against the retained model-ready panel. Notebook `03_model_training_evaluation.ipynb` contains the state-level benchmark, RF selection evidence, uncertainty intervals, and RF SHAP generation. Notebook `04_dashboard_artifacts.ipynb` validates the dashboard input contract.

## Dashboard

Run the submitted stakeholder Dash dashboard:

```powershell
.\.venv\Scripts\python.exe dashboard_stakeholder\app.py
```

Then open `http://127.0.0.1:8051`.

The dashboard reads certified state-level CSV/JSON/PNG artifacts from `data/`, `outputs/metrics/`, and `outputs/figures/` inside this source-code folder. It does not retrain models or recalculate results during runtime.
